# Hotel Reservation Changes

Applies to Northstar Lodge Canmore, Glacier View Hotel Banff, and Columbia
Trail Inn Golden. For vacation rental changes, see
`vacation-rental-policies.md`. For cancellations and refunds, see
`refund-cancellation-policy.md` — this document covers *modifications* to
an existing reservation only.

## How to Request a Change
Changes can be made online via the booking portal, by phone, or at the
front desk. Changes to a reservation already checked in must go through
the front desk.

## What Can Be Changed
- Check-in / check-out dates (subject to availability)
- Room type or bed configuration
- Number of guests
- Adding breakfast or parking packages

## Change Fees
| Timing before check-in | Fee |
|---|---|
| 72+ hours | No fee |
| 24–72 hours | $25 change fee |
| Less than 24 hours | $50 change fee, subject to availability |

Northstar Rewards Gold and Platinum members are exempt from all change
fees — see `northstar-rewards-program.md`.

## Name Changes
Reservations can be transferred to a different guest name once, free of
charge, up to 48 hours before check-in.
